**Knock puts a small animal on your Windows taskbar for each Claude Code session. When a session needs you, its animal steps up and knocks.**

This is the first public beta. It works, but expect rough edges, and please tell us how setup went.

### What's in it

- One animal per Claude Code session (fox, rabbit, cat, owl), or plain colored labels.
- Knock-and-notify when a session asks for permission or has a question, plus one reminder after 5 minutes.
- Hover for details, and click to jump to the session's window.
- A den when more than 5 sessions are open, and a "While you were away" summary when you come back.
- Pause and quiet hours, Narrator support, and it respects Windows Animation effects.

### Before you install

- **Windows 11** with the **Claude Code CLI running natively** (not WSL, not the VS Code Claude panel).
- **The installer is unsigned.** If you see "Windows protected your PC", click **More info → Run anyway**.
- **Smart App Control blocks unsigned apps.** Check Windows Security → App & browser control → Smart App Control. If it's **On**, Knock can't run.
- No auto-update yet. Newer betas install over this one, and your settings are kept.
- The installer was built by this repository's public GitHub workflow. Its SHA-256 checksum is below.

### Privacy

No telemetry, no accounts, no internet connection. Knock never reads or stores your conversations, prompts or code. Setup shows exactly what it changes in Claude Code's settings and backs the file up first.
