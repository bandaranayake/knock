**Knock puts a small animal on your Windows taskbar for each Claude Code session. When a session needs you, its animal steps up and knocks.**

This release is about reliability: Knock now remembers your sessions when it restarts, tells you plainly when something is wrong, and can hand you the details for a bug report.

### What's new since the beta

- **Knock remembers your sessions when it restarts.** After you quit and start Knock again, or restart your PC, your sessions come back as they were, with each one's terminal re-checked. A session that was knocking still knocks, without sending you a second notification, and one whose terminal is gone shows "Session ended" and fades. Knock never notifies you about time it wasn't watching.
- **Copy diagnostics**, in Settings, puts your version, Windows version, health check results, session and display counts and your Knock settings on the clipboard, so you can paste them into a bug report. Nothing is sent anywhere, and it never includes your project names, folder paths, user name, or anything you or Claude Code wrote.
- **Settings shows Knock's version**, so you no longer have to read it from the installer's file name.
- **`knock doctor`**, for anyone who prefers a command line: the same three health checks, printed in a terminal.
- **Clearer messages when something goes wrong.** Knock no longer blames another program when the real problem is that it can't write its own file, no longer tells you to press a button that isn't on the screen, and no longer shows a developer message to people running the installed app.
- **Setup stops reappearing.** It opens by itself only until you have been through it once. After that Knock starts quietly, and Settings tells you if it isn't connected.

### Before you install

- **Windows 11** with the **Claude Code CLI running natively** (not WSL, not the VS Code Claude panel).
- **The installer is unsigned.** If you see "Windows protected your PC", click **More info → Run anyway**.
- **Smart App Control blocks unsigned apps.** Check Windows Security → App & browser control → Smart App Control. If it's **On**, Knock can't run.
- **No auto-update yet.** Install this over your existing Knock; your settings are kept. Auto-update is the next release.
- The installer was built by this repository's public GitHub workflow. Its SHA-256 checksum is below.

### Privacy

No telemetry, no accounts, no internet connection. Knock never reads or stores your conversations, prompts or code. Setup shows exactly what it changes in Claude Code's settings and backs the file up first. Copy diagnostics is the only thing that gathers anything about your machine, it only copies to your clipboard, and the README lists exactly what it contains.
